Summary type

data Summary Source #

The Summary type is used by more types in the application. It is a placeholder of a longer text attribute of the types. Its internal implementation is hidden from the types. Generally the parser and the renderer types need the functions to handle the Summary values.

HasSummary type class

class HasSummary a where Source #

The HasSummary is the type class of the types which want to use the Summary type. Because the Summary must be hidden to them, there must be the class methods to read, set and modify the parameter.
