Task and its attributes

data Case Source #

The Case data type contains the parameters of the case correspondent to the workfile. Some title, a longer summary, priority and status, and of course deadline. The caseFlags attributes

The summary field currently will be implemented as Pandoc Block.

The case has an ID.
