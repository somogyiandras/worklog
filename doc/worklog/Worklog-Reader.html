extractTitleFromMeta :: Doc -> Text Source #

Returns the title based on the meta values of the pandoc transformed workfile There is no error if the title is empty

parseMetaForStatus :: Doc -> Either ParsingErrors Status Source #

Status information is metadata field. key = "closed" value = _ means Archived Status value, the case is closed key = "deferred" value = date in yyyy.mm.dd. format, where the separator can be ., / or -. The last separator is optional. Then the case is deferred untill the given date. If there is no key values of the above, then the Status is OnDesk There can be parsing error in the date, then return Left ParsingError

extractKeyWordsFromMeta :: Doc -> [Text] Source #

The metadata block can contain a keywords key, with an array value. Theese are the case keywords.

extractFlagsFromText :: Doc -> Set CaseFlag Source #

Flag information is boolean. Flag is true, if the raw text of the workfile contains the corresponding text at least once. There is no error, flags can be empty.
